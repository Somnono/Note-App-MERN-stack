# Security Policy

## Supported Versions
The following versions of this project are currently being supported with security updates:

| Version | Supported |
|----------|------------|
| Latest   | ✅ |

Older versions are not actively maintained.

---

## Reporting a Vulnerability
If you discover a security vulnerability in this project, please help us by reporting it responsibly.

To report a vulnerability:
1. **Do not** open a public GitHub issue.
2. Instead, email the maintainer directly at **your_email@example.com** with the following details:
   - Description of the vulnerability
   - Steps to reproduce the issue
   - Suggested fix (if any)

We aim to acknowledge all reports within **5 business days** and address valid issues as quickly as possible.

---

## Security Best Practices
When running or contributing to this project:
- Always keep your dependencies updated.
- Avoid committing sensitive data (like passwords, tokens, or API keys).
- Use environment variables to manage secrets.
- Use `npm audit` or `yarn audit` to detect vulnerabilities early.
