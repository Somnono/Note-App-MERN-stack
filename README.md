📝 MERN Note App

A simple cloud-based note-taking application built with the MERN stack.
Users can create, edit, and delete notes with a clean, responsive UI — accessible from any device.

🌐 Live Demo: https://note-app-8ndt.onrender.com

🚀 Tech Stack

MongoDB – Database for storing notes

Express.js – RESTful backend framework

React.js – Dynamic and responsive frontend

Node.js – Server-side runtime

Render – Deployment platform

✨ Features

✅ Create, edit, and delete notes
✅ Persistent storage via MongoDB Atlas
✅ Responsive design (desktop & mobile)
✅ RESTful API structure

⚡ Getting Started

To run locally:

git clone https://github.com/Somnono/note-app-mern.git
cd note-app-mern
npm install
npm start
