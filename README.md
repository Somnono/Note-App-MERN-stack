# MERN Note App 📝  

A simple **cloud-based note-taking application** built with the MERN stack. Users can create, edit, and delete notes with a clean and responsive UI.  

🌐 **Live Demo:** [https://note-app-8ndt.onrender.com](https://note-app-8ndt.onrender.com)  

---

## 🚀 Tech Stack
- **MongoDB** – Database  
- **Express.js** – Backend  
- **React.js** – Frontend  
- **Node.js** – Server  
- **Deployment** – Render  

---

## ✨ Features
- Add, edit, and delete notes  
- Persistent storage with MongoDB  
- Responsive design for desktop and mobile
